# ipw-product-discovery

## Work
1. State the real target actor, job-to-be-done, trigger, workaround, cost of inaction, and affected buyer/user. Mark unverified buyer assumptions as **hypotheses**.
2. Read the current connected customer journey, accepted contract, roadmap and live delivery evidence before proposing any new product or technical work.
3. Collect authorized customer/prospect evidence when accessible. Record interview dates, source, alternatives, counterexamples and disconfirming signals; never invent interest or commitments.
4. Draft the smallest falsifiable value test with a measurable customer-facing acceptance gate, numerator/denominator, time to ready, human wait vs machine time, and remaining manual interventions.
5. Rank **continue / narrow / change / stop** using customer impact, confidence, reversible effort, security and measured cost; name an owner and next decision date.
6. Keep Readiness Diagnostic commercial offer distinct from managed service capabilities. Do not treat CI status, website copy, simulated demos, or internal interest as customer adoption.

## Return
A concise customer problem statement; evidence-vs-assumption ledger; alternatives with tradeoffs; one prioritized experiment with owner, acceptance criteria and next action. Explicitly label **NOT MEASURED**, **SIMULATED**, and **CUSTOMER-ACCEPTED** status.
